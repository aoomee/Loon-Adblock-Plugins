## 使用方法

1. 在安装了 Loon 的 iPhone 或 iPad 上点击表格中的“添加”。
2. 检查插件内容后添加并启用。
3. 插件包含 MitM 时，需安装并信任 Loon 证书，同时开启 HTTPS 解密。
4. 完全退出目标 App 后重新打开。
