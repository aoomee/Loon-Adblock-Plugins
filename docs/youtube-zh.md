# YouTube 中文增强版

这是 [devchristian1337/loon-plugins](https://github.com/devchristian1337/loon-plugins) 中 `Plugins/YouTube.lpx` 的中文化版本。汉化了插件名称、选项说明、日志标签和注释；请求匹配、脚本地址及默认开关保持上游设置。原作者为 devchristian1337，汉化维护者为 aoomee。

上游插件仓库未声明开源许可证。本仓库的 MIT License 不涵盖该第三方插件，改编时保留原作者信息与源链接。

插件可配置广告处理、后台播放、字幕翻译、隐藏首页 Shorts、屏蔽频道和可选日志。后台播放、HTTP/3 回退与广告处理效果依赖 YouTube 当前接口及 Loon MitM 环境；完整媒体采样可能增加延迟。日志默认关闭，启用后会记录匹配请求数据，可通过插件选项控制并导出。
