# 去哪儿配套 Loon 清理插件 v1

面向去哪儿旅行 5.3.8 的配套网络清理规则，可与修改版 IPA 配合使用。支持范围见下表；不同版本的接口可能变化。

## 一键导入

[一键导入到 Loon](https://www.nsloon.com/openloon/import?plugin=https%3A%2F%2Fraw.githubusercontent.com%2Faoomee%2FLoon-Adblock-Plugins%2Fmain%2Fplugins%2Fqunar.plugin) · [较旧版本 Loon 兼容入口](https://www.nsloon.com/openloon/import?plugin=https%3A%2F%2Fraw.githubusercontent.com%2Faoomee%2FLoon-Adblock-Plugins%2Fmain%2Fplugins%2Fqunar-legacy.plugin)

1. 在装有 Loon 的 iPhone / iPad 上点上面的入口。Loon 3.5.1（983）及更新版本选新版；较旧版本选兼容入口，两者只启用一个。
2. 添加插件后启用脚本、复写及 MitM。使用前需安装并信任 Loon 的 MitM 证书；已完成设置的设备无需重做。
3. 插件自动加载[本仓库的脚本](https://raw.githubusercontent.com/aoomee/Loon-Adblock-Plugins/main/scripts/qunar-clean.js)，无需单独导入 `.js`。如果装过本地版，停用旧的去哪儿清理规则，避免重复匹配。
4. 在 Loon 中手动运行 **「去哪儿清理运行状态」**，查看“脚本可运行”通知或同名日志。若下载失败，检查设备是否能访问下列直链。
5. 完全退出去哪儿后重新打开，刷新「我的」，依次进入首页、行程、酒店、机票、火车票及其他常用栏目，再运行一次状态脚本。

如果一键入口未唤起 Loon，可复制对应地址到 Loon 的插件页面添加：

- 新版规则：`https://raw.githubusercontent.com/aoomee/Loon-Adblock-Plugins/main/plugins/qunar.plugin`
- 兼容规则：`https://raw.githubusercontent.com/aoomee/Loon-Adblock-Plugins/main/plugins/qunar-legacy.plugin`

一键入口采用 [Loon 官方通用链接](https://nsloon.app/docs/Scheme/)。脚本路径和版本语法见[官方 Script 文档](https://nsloon.app/docs/Script/script_v2/)，插件格式见[官方插件文档](https://nsloon.app/docs/Plugin/)。多个脚本匹配同一响应时会受匹配顺序影响；验证时应停用其他规则中与去哪儿重叠的条目。

## 本版做了什么

| 页面 / 内容 | 已加入的规则 | 当前边界 |
| --- | --- | --- |
| 我的：学生卡 | 清空对应快捷入口 | 须命中接口或已识别的返回结构 |
| 我的：贷款整排 | 清空金融卡片与金融横幅；包括该排钱包入口 | 保留订单、积分、常用工具及会员数据 |
| 我的：底部信息流、推广弹窗 | 清空推荐内容，结束分页；清理推广浮层数据 | 本地旧缓存可能先显示 |
| 行程：推广背景数据与内容流 | 清空已识别的空行程推广数据、共用内容流 | **不能靠这些网络规则移除固定的“我的行程”标签，也不能删除包内默认背景** |
| 首页：天天神券整排 | 对完整匹配的五卡片数据结构清空内容 | 结构从包内模型提取，尚无手机实际返回样本；不保证消除占位 |
| 酒店广告 | 处理已识别的原生酒店广告模型，以及共用广告位数据 | 酒店图片、房型和搜索结果不做泛化删除 |
| 火车票广告 | 清空底部广告配置 | 独立促销、弹窗仍需真实接口样本 |
| 机票广告 | 首页轮播、卡片横幅、底部广告、广告位编号与浮层 | 轮播存在本地缓存读取，旧缓存可能需要在应用内清理 |
| 跨业务广告与内容流 | 清理识别出的共用广告位结构、共用内容流接口；拦截已定位的开屏/广告预加载地址 | **并非所有租车、门票、民宿等网页或原生页面都已覆盖** |

搜索框尺寸、固定底栏、固定标签属于本地界面。这份插件不能恢复已被 IPA 修改破坏的搜索框，也不承诺替代这些本地布局修改。如果当前 IPA 的搜索框仍异常，需要另外修复 IPA 或恢复正常显示的版本。

## 这次怎样确认有没有生效

先进入上述页面，再运行状态脚本，查看通知与日志：

- **捕获响应为 0**：脚本尚未命中，可能是规则/解密域名未生效，或页面只用了缓存。不是“广告已经清完”。
- **非 JSON 多**：请求到达脚本，但返回可能是网页、二进制或额外封装，现有 JSON 规则无法修改。脚本会原样放行。
- **未识别接口 / 无目标字段**：需要根据实际请求补充适配，不能据此声称清理成功。
- **已改写大于 0**：有目标字段被改写，仍需确认页面效果；可能残留标题、空白或缓存内容。

若画面仍未变化，请发 **「去哪儿清理运行状态」的截图或脚本日志，以及仍有广告页面的进入路径**。脚本日志只记录域名、预先列明的接口名称、处理结果与字段类别，不记录 Cookie、完整网址参数、订单或返回正文。先不需要导出包含账号信息的整份抓包。

对机票轮播等明确读取本地缓存的内容，可在去哪儿内使用清理缓存功能后再打开；不要先卸载应用。出现查询异常时，停用本插件；若此前手工追加过本地规则，只移除这些条目；不要删除其他插件共用的解密域名。

## 验证情况

通过 28 项离线测试，覆盖字段处理、订单/价格/会员数据保留、异常返回、未识别接口、重复执行、数值精度保护、脚本完成回调、运行统计、配置正则及在线分发链接。测试数据是依据 IPA 中消费代码构造的样例，**不是你的手机实际抓包**。

尚未在 iPhone 或 Loon 的真实解析器中安装验收，不能保证所有广告清零。统计仅在本地保存；脚本不发出外部请求。存储、通知及完成回调按[官方 Script API](https://nsloon.app/docs/Script/script_api/)使用。


维护者可在仓库根目录运行 `node tests/qunar.test.cjs`。适配来源和未验证项见[适配依据](./qunar-evidence.json)。
